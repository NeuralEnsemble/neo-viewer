Neural Activity Visualizer

Web-browser visualisation of electrophysiology data files in any format supported by the Neo library.

The neural-activity-visualizer JavaScript app enables web-browser visualisation of electrophysiology data files in any format supported by the Neo library. It makes use of the Neo Viewer REST API.

Neo is an open-source Python API supporting 30+ file formats including proprietary formats (AlphaOmega, Plexon, NeuroExplorer), open formats (Neurodata Without Borders, Klustakwik, Elan), and generic file formats (MATLAB, ASCII, HDF5). Neo loads data into a common object model to increase interoperability. The visualizer provides interactive Plotly.js visualisations, with a FastAPI backend.
