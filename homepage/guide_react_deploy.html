Deploying the React Demo App

A step-by-step guide to deploying the Neural Activity Visualizer ReactJS demo app. The final result will be similar to the app running on this page. You will need a GitHub account — create one for free here.

Step 1

Open the GitHub repository of this project at https://github.com/NeuralEnsemble/neo-viewer .

Step 2

To have greater freedom to make changes, create a fork of this project by clicking on Fork as indicated below:

Step 3

If you are not already logged into GitHub, you will be asked to log in.

Step 4

Select the account under which you want to fork the project. You can specify a different repository name, but for now we shall use the existing name. Leave the other options as displayed and click Create fork.

Step 5

You will be redirected to your fork. The URL will be like: https://github.com/GitHub_Username/Repo_name.

Step 6

We will use Netlify to host the app. Create a free account here (you can sign up with your GitHub account). Click Log in:

Step 7

Log in to Netlify with your GitHub account:

Step 8

On the overview page, click Add new site:

Step 9

Click Import an existing project from the dropdown list:

Step 10

Select Deploy with GitHub:

Step 11

If you don't see your forked repository listed, click Configure the Netlify app on GitHub at the bottom of the page to grant Netlify access.

Step 12

Select the GitHub account under which you forked the project:

Step 13

You will be asked to grant Netlify access to your repositories:

Step 14

By default, All repositories are selected. If you prefer, click Only select repositories and choose the forked repository, then click Install.

Step 15

Once selected, your repository will be listed. Click Install:

Step 16

You will be redirected back. Your forked repository should now appear — click on it to proceed:

Step 17

You will be taken to the deployment configuration page:

Step 18

Assign a name for your site. For example, neoviewerdemo sets the URL to https://neoviewerdemo.netlify.app:

Step 19

Scroll down and set these build settings:
Base directory js/react/
Build command npm update && npm run build-lib && npm run i-all && npm run build-demo
Publish directory js/react/demo/build
Leave remaining options as they are.

Step 20

Scroll down and click Add environment variables:

Step 21

Click New variable:

Step 22

Set the key to PUBLIC_URL and value to . (a single dot):

Step 23

Click Deploy SITENAME at the bottom of the page:

Step 24

The deployment will take a few minutes. Once complete, the status will show published. Visit the URL to see your deployed app.

Step 25

The deployed app is now available at the specified URL. You can share it and redeploy at any time by pushing changes to your GitHub fork.

Step 26

Scrolling down you will see the familiar visualization:
